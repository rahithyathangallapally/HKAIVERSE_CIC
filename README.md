# CSE Curriculum Intelligence Challenge

## R22 to 2030 – Curriculum Review

This project reviews the JNTUH R22 Computer Science and Engineering
curriculum and evaluates whether it prepares students for the
software and technology environment of 2030.

## Main Finding

The Computer Science foundation should not be replaced whenever
technology changes. The curriculum should be rebalanced so students
have enough time to apply the foundation to modern and future
technologies.
